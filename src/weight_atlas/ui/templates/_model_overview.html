Operations

Working...

Sheets: hillshade + hypsometric tint + contours. Previews: auto-leveled 8-bit PNG for quick inspection. Terrain (Blender): orthographic top-view terrain rendered headlessly with Blender (requires a Blender binary on PATH or WEIGHT_ATLAS_BLENDER). Fractal terrain: per-slot fractal geometry whose parameters derive from the slot's real stats (effective_rank/kurtosis/sparsity/spectral_norm); "Fractal mode" selects fBm (height field) or SDF mosaic (Menger/Mandelbulb sculpture garden). Re-scan: re-run full scan pipeline with current spec (overwrites existing artefacts). Imported scans need the original model path set above before re-scanning.

Sheet options: "Normalized depth" projects the layer axis to 0–100 % depth (better cross-model comparability; off by default); "Drop empty columns" compresses fully-NaN slot columns out of the sheet display. Both apply to the next render only and leave the recorded spec untouched.
