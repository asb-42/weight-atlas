### M4 – Comparison/Delta Layer (all tasks complete)

#### Modules Created
- **compare/align.py** — `align_fields(fieldA, fieldB, mode, spec)` → AlignedPair
  - strict mode: identity with shape check, ValueError on mismatch with `--mode aligned` hint
  - aligned mode: normalize depth to t∈[0,1], resample to common grid (≥64 samples), linear interpolation, NaN-aware via valid masks
- **compare/delta.py** — `compute_delta(pair)` → DeltaField + `compute_summary(pair, delta)` → dict
  - Δ-fields computed on scaled channel values (B - A after channel scale)
  - Summary metrics (rel. L2, cosine similarity) computed on raw stats
  - Hotspot ranking: Top-10 by |Δ_scaled| per channel, with raw values annotated
  - Hard-reject on spec_version mismatch, warning on tool_version mismatch
- **compare/render/delta_sheet.py** — Renderer registry-ID "delta"
  - Diverging Blue→White→Red colormap (RdBu_r)
  - Symmetric limits ±q(diverging_clip) of |Δ| per channel
  - Colorbar, axis labels, NaN = grey hatched
  - PNG metadata follows sheet convention (Creation-Time fixed)
  - delta_profile_<channel>.png: 1×L strip of per-layer relative L2 (hot colormap) — the "abliteration bar"

## 2. Deviations + rationale

| Deviation | Rationale |
|-----------|-----------|
| Δ-fields on scaled values, metrics on raw stats | Scaled Δ ≈ log-ratio (modell-comparable); raw metrics capture absolute change magnitude (abliteration: "how strong was the operation?") |
| Hard-reject on spec_version, warning on tool_version | tool_version must not block comparisons if scan semantics (spec_version) are identical |
| Aligned mode = projection convention, not discovery | Documented as machine-readable convention in compare_summary.json |
| Hotspots filter NaN positions | Avoids false positives from missing slots |
| spec_version stays 1 | Compare is additive; scan output unchanged |
