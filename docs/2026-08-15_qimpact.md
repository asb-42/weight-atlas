# weight-atlas — Quantization Impact (M9)

> Status: Proposal | Target: after M5 k-quant support | Breaking: No (additive)

---

## 1. Problem Statement

A single Q4_K_M fingerprint conflates model and recipe: the atlas shows *that*
a layer has large spectral norm, but not *whether* that is the model's true
topology or an artefact of aggressive quantization. Abliteration studies
(compare, delta sheets) already treat quantization noise as a confound, but
today the only signal is a footnote.

**Goal:** a paired weight-space measurement against a reference scan — SQNR,
rel-L2, cosine, zero-flip, max-delta, and (opt-in) operator impact — that (a)
quantifies quantization damage per tensor/slot/layer, (b) exports the
calibration needed to treat quantization as a **measurement floor** in
ordinary comparisons, and (c) doubles as a recipe audit (which tensors a
mixed-precision recipe should keep at higher precision).

---

## 2. Design Principles

- **Relational property:** impact is a paired weight-space difference against a
  reference scan, never a property of one fingerprint. The loader/quantization
  combination is the measurement and is recorded as such, not warned about.
- **Weight-touching once:** `impact.py` is the only M8 component that reads
  weights. Sheet renderer, delta veil and UI read only artefacts, preserving
  the global invariant that fingerprints stay portable.
- **Strict only:** index pairing reuses align.py's strict semantics as the
  precedent. `--mode aligned` is hard-rejected with ValueError — weight-space
  error across architectures is meaningless, analogous to compare's
  spec_version hard-reject. Shape mismatch on a paired tensor → ValueError
  listing the tensor.
- **Loader-canonical:** both sides go through the loader registry +
  TensorHandle; GGUF dequant is canonical float32 (M5), so impact numbers are
  loader-independent. A cross-loader pair is the intended case.
- **Determinism:** per-tensor chunked float64 accumulation with sequential
  chunk order (no parallel reduction); tensor-level parallelism via the same
  jobs=N thread pool as scan — byte-identical for any jobs.
- **Fixed anchors, never per-model scaling:** impact channels bypass
  rank_scale/robust_scale. New scale type `fixed_anchor` (vmin/vmax, dB) in
  the channel pipeline. Per-model robust scaling would make Q4_K_M, Q6_K and
  Q8_0 sheets mutually incomparable; absolute dB anchors keep them
  comparable, in the spirit of the contour convention.

## 3. Data Flow

```
scan artefacts (A) ──┐
                     ├─► tensor pairing (strict) ─► (layer, slot, name) pairs
scan artefacts (B) ──┘         │
                               ▼
weights (A, lazy handles) ──► impact.py (chunked float64, jobs=N)
weights (B, lazy handles) ─┘   │
                                ├─► field_impact_<metric>_{raw,smooth}.tif
                                ├─► field_qtype_raw.tif
                                └─► impact_summary.json ─► manifest.json
                                │
          ┌─────────────────────┼──────────────────────────┐
          ▼                     ▼                          ▼
   Sheet (fixed dB anchors,  compare --noise-floor    Web UI impact tab
   sequential cmap,          (sub-floor delta veil)
   `· q-impact`)
```

### 3.1 Tensor pairing is a name-level join (NOT align.py field alignment)

`align.py` aligns already-rasterized `Field2D` matrices; it does **not** pair
tensor names. Impact pairs tensors by joining the two fingerprints on
`map_name(name)` → identical `(layer, slot)` and matching tensor name:

- Same (layer, slot) and same tensor name on both sides → pair.
- Same (layer, slot) but different names (e.g. GGUF `blk.N.attn_q` vs HF
  `self_attn.q_proj`) → pair via slot + layer, record both names.
- Present on one side only (MTP head, attn_sinks, vision tower) → status
  `"skipped"` per M6 convention; never a shape-mismatch crash.
- Shape mismatch on a paired tensor → ValueError listing the tensor.

`align.py`'s strict mode contributes only the **semantics** (same-architecture
only, identical indices) and its hard-reject convention — not the pairing
logic itself.

## 4. Metrics

| Metric | Definition | Role |
|--------|-----------|------|
| `sqnr_db` | `10·log10(‖A‖²_F / ‖B−A‖²_F)` | headline impact channel |
| `rel_l2` | `sqrt(‖B−A‖² / ‖A‖²)` | profile strip, veil math |
| `cos` | `Σab / (‖a‖·‖b‖)` | direction preservation |
| `zflip` | fraction of zero-ness flips | sparsity/abliteration sensitivity |
| `dmax` | `max |Δ|` | outlier clipping |
| `dspec` (opt-in) | spectral norm of (B−A), seeded rSVD (`spec.seeds.svd`) | operator impact |

### 4.1 Chunked paired accumulation

Per 1M-element chunk, float64 accumulators for Σa², Σ(b−a)², Σa·b, max|Δ|,
zero-flip count. Sequential chunk order within a tensor (no parallel
reduction); tensor-level parallelism via the same jobs=N thread pool as scan.
Byte-identical for any jobs. Values agree with vectorized float64 computation
to rounding.

### 4.2 Bounded memory

float32 payloads per side, TensorHandle.clear() after each tensor; full
tensors are never materialized in float64.

## 5. Sheet Rendering

- Sheet renderer stays generic over Field2D; `qimpact.colormap` (default
  `magma_r`) overrides the hypsometric tint, and the impact field itself is
  the height field of that sheet. Title appends `· q-impact` (precedent:
  `· normalized-depth`).
- **Fixed-anchor normalization must NOT be undone by the sheet.** The sheet's
  `filled_norm` (quantile clip) and `_per_row_normalize` display knobs would
  re-normalize the impact field and destroy cross-model dB comparability.
  Impact sheets bypass `filled_norm` and `per_row_normalize`; the fixed dB
  anchors map directly to the colormap. (The TIFF fields already carry the
  true values; this is purely a display-path correction.)
- Profile strip reuses the abliteration-bar mechanism: 1×L per-layer median
  rel_l2, hot colormap.
- Raster pixel budget applies unchanged.

### 5.1 Type map

Per-tensor `ggml_type` from the quantized side's fingerprint (M5), rasterized
as categorical integer codes (`field_qtype_raw.tif`), discrete colormap +
legend, NaN where absent. Recipe (cause) and SQNR (effect) render side by side
on the same grid.

**Fingerprint note:** `ggml_type` is recorded only for GGUF tensors
(`scan.py`). For a safetensors reference side, the type map needs a per-tensor
`dtype` added to the fingerprint (additive extension); until then the map is
GGUF-side only.

## 6. Noise-Floor Veil (compare extension)

`compare --noise-floor CALIB_COMPARE_DIR` (e.g. base-FP vs base-Q4_K_M) makes
the delta renderer read the calibration compare's per-channel |delta|
rasters; cells with |delta| ≤ floor get the same grey veil (alpha=0.25) as
normalized-depth interpolation; title appends `· noise-floor veiled`. Veil
computed on the raw field level and composed with the normalized-depth veil
(alphas union, never stack). Also available per render via the existing
sheet_knobs flow (`noise_floor=<compare_job_id>`); the scan's spec stays
untouched.

**Required dependency (additive):** compare currently emits only PNGs
(`delta_sheet_<channel>.png`, `delta_profile_<channel>.png`). The veil needs a
per-channel |delta| raster. compare must therefore also emit
`field_delta_<channel>_{raw,smooth}.tif` — a new additive artefact the veil
consumes. Without it there is nothing for the floor to read.

---

## 7. Reference Convention

Side A is reference by default (`--ref-side a|b` to swap). The reference
should be the highest-fidelity scan available. Both sides' loader +
quantization summary are recorded so floors stay interpretable across
reference fidelities (a BF16 reference has a different floor than F32).

---

## 8. Expert Panels / Vision

Same per-tensor metrics over expert tensors → `field_expert_impact_<slot>_<metric>_*`
(ExpertPanel, Layer × Expert; GGUF 3D-split sub-handles carry expert_id,
alignment holds; shape mismatch → status `"skipped"` per M6 convention).
Vision tensors flow into `field_vision_impact_*` on the vision grid, global
rows mean-aggregated like `rasterize_vision`.

## 9. Degeneration Guard

Self-impact (a scan compared against itself) yields +inf SQNR; stored as NaN
and flagged by the existing per-channel diagnostics (`valid_fraction < 50%` →
warning + UI banner).

---

## 10. Spec Extension

`atlas_spec.v2.4.json` may include a `qimpact` block (all optional, defaults
shown):

```json
{
  "qimpact": {
    "metrics": ["sqnr_db", "rel_l2", "cos", "zflip"],
    "operator_impact": false,
    "db_range": [5, 60],
    "colormap": "magma_r",
    "profile_strip": true,
    "type_map": true
  }
}
```

`spec_version` stays 4 (additive extension documented here per spec; never
bump for new keys).

## 11. `impact_summary.json` Schema

```json
{
  "ref_side": "a",
  "model_a": { "loader": "safetensors", "quantization": {}, "n_tensors": 0 },
  "model_b": { "loader": "gguf", "quantization": {}, "n_tensors": 0 },
  "alignment": { "mode": "strict", "n_pairs": 0, "skipped": [] },
  "global": { "median_sqnr_db": 21.3, "p05_sqnr_db": 12.8, "median_rel_l2": 0.071 },
  "per_type": [ { "ggml_type": "Q4_0", "n": 512, "median_sqnr_db": 20.1 } ],
  "hotspot_ranking": [ { "layer": 12, "slot": "mlp_down", "sqnr_db": 9.4 } ]
}
```

Hotspot ranking = top-k lowest SQNR: the tensors a mixed-precision recipe
should keep at higher precision — the visualization doubles as a recipe audit.

## 12. CLI

```
weight-atlas qimpact SCAN_A SCAN_B --out DIR --weights-a PA --weights-b PB [--jobs N] [--ref-side a|b]
weight-atlas compare A B --out DIR --mode strict --noise-floor CALIB_COMPARE_DIR
```

### Artefacts

`field_impact_{sqnr_db,rel_l2,cos,zflip}_{raw,smooth}.tif`,
`field_qtype_raw.tif`,
`field_expert_impact_<slot>_sqnr_db_{raw,smooth}.tif`,
`field_vision_impact_sqnr_db_{raw,smooth}.tif`, `impact_summary.json`;
PNGs `impact_sqnr_db.png`, `impact_profile.png`, `qtype_map.png`. Render
discovery via manifest.json (authoritative), no timestamps, PNG metadata
fixed, TIFF byte-identical on second run (SHA-256 manifest extended with the
new fields).

## 13. Smoke Test

Bonsai-8B fixture; synthesize a Q4_0 copy with the canonical block-wise math
(32-element blocks, f16 scale). Assert:
1. per-tensor sqnr_db inside the analytic uniform-noise band
   (≈`10·log10(12·var/step²)`) ± 3 dB;
2. an injected outlier tensor (10× scale on one mlp_down) ranks top-1 lowest
   SQNR — outliers crush 4-bit range;
3. second run SHA-256 identical;
4. `--mode aligned` raises ValueError;
5. veil mask asserted on the boolean mask array (never SSIM), sub-floor
   deltas veiled, super-floor deltas not.

---

## 14. Migration & Dependency

Additive: no re-scan required; compare without `--noise-floor` is
byte-identical to current output. Dependency: full k-quant support
(Q4_K/Q6_K, M5 backlog) is required before impact can scan Q4_K_M; until then
impact validates on F16/BF16/Q8_0/Q4_0.

## 15. Design Review Corrections (from code walk)

1. **Pairing is a name-level join** over fingerprints via `map_name` →
   `(layer, slot)`, not align.py field alignment (§3.1).
2. **compare must emit per-channel |delta| rasters** for the noise-floor veil;
   it emits only PNGs today (§6).
3. **Impact sheets must bypass `filled_norm`/`per_row_normalize`** so fixed dB
   anchors survive the display path (§5).
4. **Fingerprint needs per-tensor `dtype` for safetensors** type_map; today
   only GGUF records `ggml_type` (§5.1).
5. **Milestone label:** M8 is taken (Activity Mode); this milestone is **M9**.
